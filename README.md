# 하하호호 스튜디오 · 비어밤 특별판 실행 안내

## 처음 한 번
1. 이 폴더에서 `npm install` → `npm run build`
2. `.env` 에 `OPENAI_API_KEY` (또는 운영자 모드 > AI 설정에서 키 저장)
3. `.env` 에 관리자 로그인 `ADMIN_ID`, `ADMIN_PASSWORD` (값은 `.env` 에만 있음 · 이 안내서나 다른 곳에 적지 마세요)

## 운영 순서: 켜기 → 로그인 → 손님 받기
1. **켜기**: `start-kiosk.bat` (또는 `npm start` 후 http://localhost:3000)
2. **로그인**: 첫 화면이 **관리자 로그인**입니다. `.env` 에 있는 아이디·비밀번호를 넣고 [로그인] (비밀번호는 ●로 가려짐, 5번 틀리면 1분 잠금)
3. **손님 받기**: 로그인하면 바로 손님 첫 화면(테마 고르기)이 열립니다.
   - 새로 고침(F5)해도 로그인은 유지됩니다. 서버를 껐다 켜거나 **로그아웃**하면 다시 로그인 화면이 나와요.
   - 운영자 화면: 손님 화면 **왼쪽 아래 작은 [관리자] 버튼** 또는 Ctrl+Shift+O. 로그아웃 버튼은 운영자 화면 위쪽에 있어요.
   - 다시 만들기는 손님별 **횟수 제한 없음**. 대신 1분 상한·하루 생성 상한·하루 AI 예산(운영자 화면 > AI 설정)에 닿으면 "잠시 쉬어 갈게요" 안내가 나옵니다.

## 행사 당일: P 한 번으로 바로 인화 (인쇄 창 없이)
1. **Windows 기본 프린터**를 인화기로 정합니다. (설정 > 블루투스 및 장치 > 프린터 > 인화기 > 기본값으로 설정, "Windows에서 기본 프린터 관리" 끄기)
2. 인화기 기본 설정(프린터 속성)에서 용지 **5×7 인치(127×178mm)**, 여백 없음(테두리 없음)으로 맞춥니다.
3. `start-kiosk.bat` 을 두 번 누릅니다.
   - 검은 서버 창이 뜨고(닫지 마세요), Chrome 이 **화면의 80% 크기 창으로 가운데**에 열립니다(작업 표시줄·윈도우 버튼이 보임, 2026-10-12 팀 요청).
   - 이 Chrome 은 `--kiosk-printing` 으로 열려서 **결과 화면에서 P 한 번이면 인쇄 창 없이 바로 인화**됩니다.
   - 주소에 `?kiosk=1` 이 붙어 있어 인화 숫자를 바로 셉니다.
4. 처음 한 번은 리허설에서 실제로 1장 뽑아 용지·여백·색을 확인하세요. (실기기 확인 필요)
   - 처음 인화가 엉뚱한 프린터로 가면: 그 Chrome 창에서 Ctrl+P → 대상 프린터를 인화기로, 용지 5×7, 여백 없음으로 한 번 고르고 인쇄 → 다음부터는 그 설정을 씁니다.
5. 끝낼 때: Chrome 은 Alt+F4, 서버 창은 닫기.

> 주의: 일반 Chrome 이 이미 같은 프로필로 열려 있으면 옵션이 안 먹습니다. 그래서 행사 전용 프로필(`%LocalAppData%\hahahoho-kiosk-chrome`)로 따로 엽니다.

## 바로가기 없이(일반 Chrome) 쓸 때
- `npm start` 후 http://localhost:3000
- P 를 누르면 인쇄 창이 뜹니다. 창이 닫히면 화면 아래에 **"직원 확인 · 인화 됐나요?"** 띠가 뜹니다.
  - **Enter = 됐어요**(인화 숫자 +1), **Esc = 안 했어요/취소**(세지 않음)

## 직원 단축키 (한/영 상관없이 동작)
| 키 | 하는 일 |
|---|---|
| Ctrl+Shift+O | 운영자 화면 열기 (로그인된 상태 · 왼쪽 아래 [관리자] 버튼과 같음) |
| Ctrl+Shift+L | 운영자 화면 바로 닫기 (손님 화면으로) |
| G / F / R | 이름·사진 화면: 방금 받은 사진(하하호호업로드·카톡 중 최신) / 사진 고르기(하하호호업로드 폴더 썸네일) / 다시 고르기 |
| 1~9 / O / Esc | 사진 고르기 화면: 그 번호 사진 고르기 / 다른 위치에서 고르기(Windows 파일 창) / 닫기 |
| P / M / Home | 결과 화면: 인화 / 한 번 더 만들기 / 처음으로 |
| Enter / R / Home | 실패 화면: 다시 시도(의미 있을 때만) / 사진 다시 고르기 / 처음으로 |

- 로그인 화면이 다시 보이면 = 서버를 다시 켰거나 로그아웃된 것 → `.env` 의 아이디·비밀번호로 다시 로그인.

## 결과 사진 폴더 (팀 공용 · 카톡 전달·인화용)
- 사진이 완성될 때마다(다시 만들기 포함) **`C:\하하호호스튜디오\날짜\`** 에 인화용 최종본(필름 띠 도장 포함, 1500×2100 jpg)이 자동 저장됩니다. 폴더가 없으면 앱이 켜질 때·저장할 때 만듭니다.
- 파일 이름: `손님번호_이름_테마_몇번째.jpg` → 예) `C:\하하호호스튜디오\2026-10-16\001_김순자_궁중한복_1.jpg`
  - 이름이 없으면 `손님-001`, 파일 이름에 못 쓰는 글자(`/ : * ? " < > |`)는 `_` 로 바뀝니다. 다시 만들면 `_2`, `_3` …
- **카톡으로 보내기**: 운영자 모드 > 사진 찾기 > 손님 이름 검색 → **[폴더 열기]**(탐색기에서 그 사진이 골라진 채로 열림) → 파일을 카카오톡 PC 대화창으로 끌어다 놓기. 탐색기가 안 열리면 **[경로 복사]**.
- 위치 바꾸기: 운영자 모드 > AI 설정 > 결과 사진 폴더 (또는 `.env` 의 `RESULT_DIR`). 팀원 노트북마다 같은 위치로 두면 됩니다.
  - 한 번 [설정 저장]을 누른 뒤에는 화면에서 정한 위치가 `.env` 보다 우선합니다.
- 도장 없는 원본이 필요하면 같은 설정에서 "도장 없는 원본도 저장"을 켜면 `날짜\원본\` 에 함께 저장됩니다(기본 꺼짐).
- **자동 삭제(개인정보)**: 손님께 "행사 종료 7일 뒤 삭제"를 약속했으므로, 행사 종료일 + 보관일이 지나면 이 폴더의 날짜 폴더 사진(jpg)도 지웁니다. 운영자 화면에 "N일 뒤 지워져요"가 나옵니다. 끄려면 AI 설정의 "결과 폴더도 자동 삭제"를 해제하세요.
  - 지우는 것은 `결과 폴더\YYYY-MM-DD\` 와 그 안 `원본\` 의 jpg 뿐입니다. 결과 폴더 바로 아래 파일, 다른 이름의 폴더, 직접 넣은 다른 파일은 건드리지 않습니다.
- 앱 안의 `data` 폴더(손님 기록·원본)는 그대로 있어서 사진 찾기·다시 만들기는 지금처럼 됩니다.

## 창 크기 (전체 화면 대신 80% 창)
- `start-hahahoho.bat`(바탕화면 바로가기)·`start-kiosk.bat` 은 Chrome 을 **앱 창(주소창 없음)** 으로, 작업 표시줄을 뺀 화면의 **80%** 크기로 가운데에 엽니다. `--kiosk-printing`(P 한 번 인화)과 전용 프로필은 그대로입니다.
- 크기 바꾸기: 배치 파일 맨 위 `set "SCALE=80"` 의 숫자(50~100)를 바꾸거나, 앱 폴더 `.env` 에 `WINDOW_SCALE=90` 처럼 한 줄 넣습니다(**.env 쪽은 앱을 업데이트해도 유지**). 계산은 `window-size.ps1` 이 합니다.
- 앱 화면은 창 크기에 맞춰 16:9 비율로 줄어듭니다. 창을 마우스로 끌어 크기를 바꿔도 됩니다. 전체 화면이 필요하면 F11.
- 이미 그 Chrome 창이 열려 있으면 새 크기가 적용되지 않으니, 창을 모두 닫고 다시 여세요.

## 사진 올리기 폴더 (하하호호업로드)
- 휴대폰으로 찍은 손님 사진을 노트북 바탕화면의 **`하하호호업로드`** 폴더에 넣으면, 이름·사진 화면에서 **F(사진 고르기)** 를 눌렀을 때 그 폴더 사진이 **최신순 썸네일**로 뜹니다 → 숫자키/클릭 → "이 사진 맞나요?" 확인.
  - 브라우저의 파일 창은 보안상 시작 폴더를 정할 수 없어서, 앱이 직접 폴더를 보여 줍니다. 맨 아래 **[다른 위치에서 고르기](O)** 를 누르면 예전 Windows 파일 창도 쓸 수 있어요.
- **G(방금 받은 사진)** 는 하하호호업로드 폴더와 카카오톡 받은 파일 폴더 **둘 다** 보고 가장 최근 사진을 가져옵니다. (3분 지난 사진·앞 손님 사진 경고는 그대로)
- 폴더 자동 찾기 순서: `D:\OneDrive\Desktop\하하호호업로드` → `D:\Desktop\하하호호업로드` → `%OneDrive%\Desktop\하하호호업로드` → `%USERPROFILE%\OneDrive\Desktop\하하호호업로드` → `%USERPROFILE%\Desktop\하하호호업로드`. 하나도 없으면 **실제 바탕화면 위치에 새로 만듭니다**(서버 창 첫머리에 `[업로드 폴더] …` 로 표시).
- 위치 바꾸기: 운영자 화면 > AI 설정 > 사진 올리기 폴더 (비우면 자동) 또는 `.env` 의 `UPLOAD_DIR`.
- 자동 삭제: **기본 꺼짐**(팀원 개인 폴더라서). 필요하면 AI 설정에서 "업로드 폴더 사진도 자동 삭제"를 켜면 행사 종료일 + 보관일 뒤 그 폴더 바로 안의 사진 파일(행사 종료일까지 들어온 것)만 지웁니다.

## 팀 공동 규칙 (AI 지시문) · 규칙 고치는 법
- 모든 사진 지시문 맨 앞에 **팀 공동 규칙**이 들어갑니다. 앱 지시와 겹치거나 부딪히면 **팀 규칙이 우선**입니다.
  - `config/global-rules.md` : 한국어 원문 보관 (원본 `App 개발\지침 규칙\공동규칙.hwpx` 를 옮겨 적음 + 맨 아래 "추가(2026-10-12 대표님 확인)" 50대 항목)
  - `config/global-rules.en.md` : **실제로 AI에 들어가는 영어 번역본** (기본)
- **고치는 법**
  1. 메모장으로 `config/global-rules.md`(한국어)를 고칩니다.
  2. 같은 내용을 `config/global-rules.en.md`(영어)에도 고칩니다. (영어로 고치기 어려우면 써니팀 개발자에게 부탁)
  3. 저장하면 **다음 사진부터 바로** 적용됩니다(서버 재시작 필요 없음). 파일은 UTF-8 로 저장하세요.
  - `<!-- ... -->` 안의 글(맨 위 안내)은 AI에 보내지 않습니다.
  - 영어본을 지우거나 비우면 한국어 원문을 대신 씁니다. 둘 다 없으면 앱 기본 지시만 씁니다. 서버 창 첫머리에 `[팀 공동 규칙] config/…` 로 어떤 파일을 쓰는지 나옵니다.
  - 설치된 노트북은 `C:\하하호호스튜디오앱\config\` 에 있습니다. **새 버전을 설치하면 이 파일들이 꾸러미 것으로 바뀌니**, 고친 규칙은 개발 폴더에도 반영해 주세요.
- 앱이 덧붙이는 것: 손님 사진 한 장 + 고른 레퍼런스의 장면 설명(글), 커플 규칙, 구도(머리~무릎 위, 완전 전신·발끝 금지), 실존 인물·상표·글자 금지, 테마 메모, 다시 만들기 요청.

## 실수로 F5·처음으로 눌렀을 때
운영자 모드 > 사진 찾기 > 손님 이름 검색 → **[손님 화면에 띄우기]** (완성 사진이 있는 손님) 또는 **[이어 하기]** (실패한 손님: 원인을 고친 뒤 다시 만들기, 손님 수는 중복으로 세지 않음).
